| Параметр | Значение |
| :--- | :--- |
| **Модуль** | Страница «О социальной проблеме» (Social Adaptation) |
| **Критичность (Severity)** | 🔥 Критический (Critical) |
| **Приоритет (Priority)** | ⚡ Высокий (High) |
| **Автор** | Тарасова Наталья |

---

### 📝 Описание дефекта
В подвале информационной страницы «О социальной проблеме» кнопки «Узнать подробнее» в карточках программ фонда («Билет в жизнь» и «Легкий старт») перенаправляют пользователей на устаревшие (архивные) изолированные страницы вместо актуального общего раздела программ. Это нарушает единство навигации и демонстрирует пользователю неактуальный интерфейс.

### 🛠️ Окружение (Environment)
* **Реальный девайс:** Смартфон Poco X7 Pro (разрешение 412x915px, DPR 3.5), Android 15
* **Браузер:** Мобильный Google Chrome 151.0.7922.177

### 📋 Предусловия (Pre-conditions)
1. Открыт мобильный браузер Google Chrome на смартфоне Poco X7 Pro.
2. Выполнен переход на страницу описания проблемы: `https://academy-of-life.ru/about-social-adaptation`

### 👣 Шаги воспроизведения (Steps to Reproduce)
1. Проскроллить страницу вниз до блока «Подробнее о возможном решении социальной проблемы».
2. Найти карточку программы **«Билет в жизнь»** и совершить тап по кнопке **«Узнать подробнее»**. Проверить URL.
3. Вернуться назад и найти карточку программы **«Легкий старт»**. Совершить тап по кнопке **«Узнать подробнее»**. Проверить URL.

### 🎯 Ожидаемый результат (Expected Result)
При клике на любую из кнопок «Узнать подробнее» в карточках происходит переход на общую структурированную страницу с актуальным описанием всех программ фонда: `https://academy-of-life.ru/programs`.

### ❌ Фактический результат (Actual Result)
Интерфейс выполняет перенаправление на архивные, не поддерживаемые страницы сайта:
1. Для программы «Билет в жизнь» ➡️ `https://academy-of-life.ru/bilet-v-zhizn`
2. Для программы «Легкий старт» ➡️ `https://academy-of-life.ru/legkiy-start`

---

### 💡 Комментарий для разработки (Technical Notes)
Адреса `/bilet-v-zhizn` и `/legkiy-start` исключены из новой структуры сайта, но ссылки на них не были обновлены в данном контентном блоке.
**Требуемые исправления:**
В файле разметки компонента страницы `about-social-adaptation` для кнопок «Узнать подробнее» необходимо заменить старые значения атрибутов `href` на актуальный общий адрес роута:
* Изменить с `href="/bilet-v-zhizn"` на `href="/programs"`
* Изменить с `href="/legkiy-start"` на `href="/programs"`
