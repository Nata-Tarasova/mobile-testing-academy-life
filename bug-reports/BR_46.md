# 📄 Баг-репорт BR_46: Нарушение логики перехода в главном меню при выборе пункта «Программы»

| Параметр | Значение |
| :--- | :--- |
| **Модуль** | Меню сайта (Navigation) |
| **Критичность (Severity)** | 🔥 Критический (Critical) |
| **Приоритет (Priority)** | ⚡ Высокий (High) |
| **Автор** | Тарасова Наталья |

---

### 📝 Описание дефекта
При тапе на пункт меню «Программы» в мобильной версии сайта не происходит переход на целевую страницу. Вместо этого интерфейс раскрывает устаревшую структуру подменю с рудиментарными пунктами, полностью блокируя доступ пользователя к общему разделу программ.

### 🛠️ Окружение (Environment)
* **Симуляция девайса:** Смартфон Poco X7 Pro (разрешение 412x915px, DPR 3.5)
* **Браузер:** Google Chrome 151.0.7922.174 DevTools
* **ОС:** Windows 11

### 📋 Предусловия (Pre-conditions)
1. Открыта панель инструментов разработчика Google Chrome DevTools.
2. Включена эмуляция смартфона Poco X7 Pro.
3. Выполнен переход на главную страницу стенда: `https://academy-of-life.ru`

### 👣 Шаги воспроизведения (Steps to Reproduce)
1. Нажать на кнопку-бургер в шапке сайта для вызова основного меню навигации.
2. Совершить тап по текстовому названию пункта меню **«Программы»**.
3. Оценить поведение интерфейса и текущий URL в адресной строке браузера.

### 🎯 Ожидаемый результат (Expected Result)
Тап по пункту «Программы» осуществляет мгновенный переход пользователя на целевую страницу `https://academy-of-life.ru/programs`.

### ❌ Фактический результат (Actual Result)
Переход на страницу `/programs` не происходит, URL в адресной строке не меняется. Вместо этого в бургер-меню разворачивается скрытый список со старыми подпунктами: *«О программах», «Билет в жизнь», «Легкий старт»*.

### 💡 Комментарий для разработки (Technical Notes)
Так как пункт «Программы» по актуальным требованиям должен быть линейным (нераскрываемым), необходимо вернуть элементу стандартное поведение ссылки `href="/programs"` и полностью удалить дочерний контейнер со старыми подпунктами (вложенный тег `<ul>`).
